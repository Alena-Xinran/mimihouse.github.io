Service Description

The App is a fully local iOS app (with an optional Apple Watch companion). Main features include:

  • Wind-up focus timer: spin to set duration, cicada white noise during focus, and alerts if you idle with the phone;
  • Swing play: gyroscope-driven friction sound and haptics;
  • Duel mode: nearby peer-to-peer competition;
  • Optional local stretch reminders.

The App provides no accounts, cloud sync, or backend service. Features depend on device sensors and system permissions.
